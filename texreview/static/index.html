An agent proposes edits as JSON; nothing touches your files until
     you decide. Accept or reject each suggestion, then
     Apply accepted rewrites the manuscript (a one-time
     .bak is kept next to each file). Filter by status or
     tag; the directory is re-scanned on every refresh, so an agent can
     keep adding passes while you review.
